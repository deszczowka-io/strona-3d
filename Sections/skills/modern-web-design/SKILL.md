# Modern Web Design Skill

## Purpose
Produce creative, non-generic web design specs for frontend-engineer and ui-ux-designer to implement.

## Principles
- **No template layouts.** Avoid centered hero + three feature cards + CTA unless the brief calls for it.
- **Typography first.** Establish a type scale before color or layout.
- **Intentional whitespace.** Dense content is the enemy of premium feel.
- **Motion has purpose.** Every animation serves hierarchy or storytelling, not decoration.

## Output
- `visual-system.md` — color palette, type scale, spacing, motion character.
- `layout-direction.md` — composition philosophy, grid rationale.
- Approval criteria for ui-ux-designer and frontend-engineer.

## Compatibility
Pure CSS/HTML concepts — works with any stack. No new dependencies.
